This page simulates a dealership website

The chat bubble in the corner is the embeddable AI assistant. It runs on Claude and can handle the full customer journey for any dealership:

  • Stock search — "Have you got any hybrid SUVs under £22k?"
  • Vehicle details — "Tell me more about the Sportage."
  • Finance (FCA-compliant) — presents only the dealer's signed-off representative example with the credit-broker disclosure; never improvises payment figures.
  • Part-exchange valuation — "What's my 2019 Fiesta with 41k miles worth?"
  • Test drives, servicing & MOT — "Book me a test drive Saturday at 2pm."
  • Opening hours, directions & offers — "Are you open Sunday? Any current deals?"
  • Lead capture — contact details flow straight to the admin dashboard.

Embedding on a real dealership site

One script tag, anywhere on the page:

<script src="https://your-chatbot-host/widget.js" async></script>

All branding — colors, logo, bot name, greeting, position — comes from config/dealership.config.json on the server. Reselling to a new dealership means swapping that one file. No code changes.
